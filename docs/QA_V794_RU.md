# Диагностика v7.9.4

## Результат доступных проверок

- Полный набор: **170 тестов прошли, 0 ошибок, 0 пропусков**. Проверены Qt и старый Tk-интерфейс с виртуальным графическим дисплеем.
- Статический анализ Python (ошибки синтаксиса и неопределённые имена): пройден.
- Масштабирование 100%, 125%, 150%: по три размера окна и 12 состояний первого запуска на каждом масштабе.
- Собранная программа PyInstaller для Linux: проверены запуск, оба языка, все 115 PNG по контрольным суммам, Unicode-пути, атомарные правки, отмена, запись копии и перезапись с проверенным бэкапом. Это отдельная проверка собранного приложения, а не только исходников.
- Игровые данные: сопоставлены 1233 записи RU/EN, 307 обычных кварцев и 1240 записей английского каталога. У всех 1181 видимых базовых записей найдена привязка к оригинальному PNG. Привязка к общему значку типа не означает индивидуальную покадровую проверку каждого предмета в игре.
- На копиях настоящего save016.dat выполнены 100 случайных пакетных правок и цикл отмены/копии/бэкапа/повторного открытия. Исходный файл и байты вне таблицы инвентаря не изменены.

## Исправления этого прохода

1. Исправлен ошибочный GUID перенесённой папки Windows Saved Games: автопоиск теперь обращается к документированному FOLDERID_SavedGames.
2. Поиск учитывает текст, показанный в карточке, в том числе восстановленные английские описания кварцев.
3. После сканирования карточка выбранного предмета обновляется; неприменённый ввод количества сохраняется. Импорт и сканирование используют общий механизм обновления.
4. Стандартный запуск, зависимости и Windows-сборка переключены на qt_window.py. Старый app.py сохранён для совместимости. Версия Qt-окна — 7.9.4.
5. Из репозитория убран прежний набор условных значков категорий. Используются проверенные оригинальные PNG; источники сохранены.
6. Подготовлены упаковка Windows ZIP с SHA-256 и проверка файловых операций внутри EXE до создания черновика релиза. README RU/EN и скриншоты обновлены.

Предыдущие исправления сохранены: атомарные пакетные изменения, защита от внешнего изменения исходного файла, сохранение DLC при импорте английской базы, подтверждённые иконки рыб и предметов сияющей пом, исключение ID 249 из добавления, восстановление шести английских описаний кварцев.

## Незавершённые внешние проверки

Запись в GitHub недоступна текущему подключению: создание ветки вернуло **403 Resource not accessible by integration**. Изменения подготовлены в локальной ветке; репозиторий и существующий релиз v7.0.1 на GitHub не изменены. Поэтому удалённые Actions, Windows EXE и публикация нового релиза в этом проходе не выполнены. Настройки сборки готовы, но их наличие не является доказательством успешной сборки Windows.
