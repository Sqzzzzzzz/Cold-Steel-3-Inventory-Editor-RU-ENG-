# Диагностика и исправления v7.9.6 — 29 октября 2026

База: актуальный main `801a1abb0a3ed791fb97683417c6b23bd0a52c3f` (v7.9.4). Версия включает исправления v7.9.5 и результаты независимого повторного ревью. Существующие изменения владельца сохранены.

## Исправления независимого ревью

- **Экспорт CSV мог затереть открытое сохранение.** Воспроизведено только на временной синтетической копии. Теперь запись выполняется атомарно, запрещены исходный файл, его файловые ссылки и расширения кроме `.csv`. Отсутствующее расширение добавляется автоматически. UTF-8 с BOM, RU/EN-названия и текущие несохранённые количества сохранены; экспорт не сбрасывает правки и отмену. Ошибки переведены на оба языка.
- **Английское повторное сканирование меняло язык нейтральных русских названий.** Для EP 1 и подобных записей сохраняются русские название, описание и метка языка, включая старые кэши без меток. Пустое исходное описание не заменяется английским в русской базе; существующее отображение английского текста при отсутствии русского сохранено. Английские данные обновляются отдельно. Проверен перезапуск.

Добавлены 18 регрессионных случаев, включая файловые ссылки, отказ атомарной замены, диалог Qt, старый кэш, пустые описания и смешанные каталоги. Независимый проверяющий подтвердил исправления; блокирующих замечаний в проверенном diff не осталось.

## Дефекты, выявленные Windows CI

Первые удалённые прогоны выявили расхождения геометрии счётчиков и полей при стандартном стиле Windows. Подписи адаптированы к измеренной ширине текста; заголовку дерева разрешено сжимать колонку названий. Дополнительно исправлен сам стенд: он теперь использует Fusion, как реальная точка входа программы, и показывает каждую вкладку перед проверкой её геометрии. Скрытая страница Qt может хранить размеры до последней компоновки. Проверки видимости счётчиков, подписей и пятизначного ID остаются включёнными в Windows CI. Следующий прогон подтвердил реальное сжатие поля ID из-за предпочтительной ширины QSpinBox. Поля теперь делят доступное место с явными минимальными ширинами по метрикам шрифта; дополнительно проверяется отображение количества 99.
