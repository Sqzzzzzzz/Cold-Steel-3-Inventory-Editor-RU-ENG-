# Диагностика и исправления v7.9.5 — 29 октября 2026

Работа выполнена по актуальному main: `801a1abb0a3ed791fb97683417c6b23bd0a52c3f` (v7.9.4). Существующие исправления Windows-путей, состав пакета с оригинальными иконками и прежние настройки CI сохранены.

## Найдено и исправлено

1. **Причина падения Python 3.10 установлена и воспроизведена.** При установке разрешённой ранее PySide6/Shiboken 6.12.0 повторная отрисовка приводит к `Fatal Python error: none_dealloc: deallocating None` и коду 134. Минимальный опыт с 1000 вызовами QPainter.fillRect уменьшает счётчик ссылок None на 1000. На проверенной версии 6.11.3 изменение равно 0. Зависимость ограничена диапазоном `>=6.7,<6.12`; Python 3.10 остаётся в CI. Это наблюдение по установленным бинарным пакетам, а не утверждение о конкретной строке исходников Qt.
2. **Ложные пометки языка.** Записи вроде EP 1 в русском каталоге ошибочно получали [EN], когда названия совпадали в обоих языках. Теперь учитывается явный язык записи; для старого кэша без меток язык исходной базы определяется один раз. Настоящие английские записи сохраняют пометку. Названия и игровые описания не переписываются.
3. **Обрезанные счётчики категорий.** Числа вынесены в отдельный столбец, размер которого Qt рассчитывает по содержимому. Проверены четырёхзначные итоги, каталог, инвентарь, удаление и отмена. Ширина панелей остаётся фиксированной. Полное название доступно в подсказке.
4. **Состав локальной Windows-сборки.** Скрипт теперь включает те же пути оригинальных PNG, что и GitHub workflow. Старые условные иконки категорий в EXE не включаются.

CI дополнен подробными именами тестов и диагностикой аварий Python. Регрессионная проверка выполняет 10 000 операций отрисовки в отдельном процессе: возможное нативное падение получает понятный результат теста.

## Применение

`CS3_Inventory_Editor_v7.9.5_UPDATE.zip` содержит изменённые файлы относительно указанного main. Его содержимое нужно перенести в корень локального репозитория с заменой, включая `.github`, `tests` и `docs`. При запуске исходников через «Запустить.bat» зависимость Qt обновится до совместимого диапазона. Для самостоятельного EXE требуется новая Windows-сборка через «Собрать_EXE.bat» или GitHub Actions.
