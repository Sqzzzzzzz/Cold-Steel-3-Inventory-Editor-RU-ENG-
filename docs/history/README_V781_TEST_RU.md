# CS3 Inventory Editor v7.8.1 — тестовая сборка исходников

Эта сборка продолжает v7.8.0: шестиугольная сетка фона и адаптивные размеры колонок каталога/инвентаря. Ядро сохранений не изменялось.

**Запуск в Windows:** распаковать ZIP, запустить `Run_Qt_Preview.bat`. Для запуска необходим Python и установка PySide6 (скрипт делает это автоматически при доступе к Интернету). Для сборки EXE — `Build_Qt_Preview_EXE.bat` на Windows.

**Важно:** это исходники и BAT для тестирования, не готовый Windows EXE. Сначала работайте с копией сохранения. Реальная загрузка сохранения в игре и запуск на Windows в текущей среде не проверялись.
