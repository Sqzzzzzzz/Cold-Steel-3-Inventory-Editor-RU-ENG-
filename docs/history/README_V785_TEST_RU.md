# Cold Steel III Inventory Editor — v7.8.5 Qt HUD BETA

Это тестовая сборка следующего шага развития игрового Qt-интерфейса.

## Что изменено
- Заменён задний размытый фон на новый оригинальный фон, лучше подходящий под стилистику Cold Steel III.
- Сохранена единая игровая тема и предыдущие улучшения HUD-компоновки.
- Ядро редактора сохранений не менялось.

## Как запустить
1. Распакуй архив.
2. Запусти `Run_Qt_Preview.bat` на Windows.
3. Для быстрой локальной проверки интерфейса можно использовать `Проверить_Qt_GUI_БЕТА.bat`.

## Зачем эта версия
Цель версии — улучшить атмосферу интерфейса и приблизить общий вид к желаемой стилистике при сохранении читаемости и стабильности.
