# QA — CS3 Inventory Editor v7.8 Qt HUD BETA

## Проверено

- Python: 3.13; PySide6 Essentials: 6.12.0 (предоставлен пользователем локально).
- Полный запуск новой Qt-оболочки в headless/offscreen режиме, захват экранов 1650×920 и 1320×760.
- 73/73 теста прошли; ранний запуск без X-дисплея давал ошибки *только* Tk-тестов, исправлено запуском под Xvfb.
- Проверены изменения количества и undo, сохранение копии без изменения оригинала, категории и массовые операции (существующие регрессионные тесты).
- Добавлены пять Qt-тестов: визуальный фон и пиктограммы, резервные иконки, адаптивная таблица, обновление избранного, языки/навигация без изменения сохранения.
- Проверены существование PNG, отсутствие игровых таблиц в коде и доступность Windows BAT.

## Ограничения

- Запуск/сборка EXE непосредственно на Windows и реальная загрузка отредактированного сохранения игрой здесь не проверены.
- Скриншоты захвачены с тестовым сохранением и пользовательским локальным набором иконок; проект не содержит оригинальные игровые PNG.
- Неподтверждённые сопоставления иконок отдельных видов рыб и декоративных предметов остались без изменений.
- Интерфейс вдохновлён референсом, но точная реализация светящихся шестиугольных эффектов ещё не завершена.
