# Проверка v7.9.0 Qt Reference HUD BETA

Дата: 26 октября 2026.

## Результат

**52 теста пройдены.** Проверка выполнена в Linux с Python 3.12 и PySide6 Essentials 6.12, стиль Fusion, Qt offscreen. Все скриншоты получены от настоящих Qt-виджетов этого архива.

Проверены:

- Изменение количества, групповое применение, отмена и восстановление исходных байтов.
- Запись отдельной копии, проверка оригинала, резервное копирование и блокировка перезаписи при внешнем изменении файла.
- Чтение таблиц, сканирование игры и DLC, независимость бета-профиля.
- Переключение RU / EN с сохранением введённого, но ещё не применённого количества.
- Независимые фильтры каталога и инвентаря; групповые действия только при множественном выделении.
- Повторное изменение размера и переключение трёх разделов: 1280×720, 1320×760, 1536×864 и 1650×920. Правая панель остаётся внутри окна; описание доступно через собственную прокрутку.
- Изоляция демонстрации от пользовательского профиля и блокировка записи синтетического сохранения из демонстрационного режима.

Байтовым сравнением с приложенной v7.8.5 подтверждено, что не менялись: cs3_save.py, qt_backend.py, catalog_core.py, game_scan.py, save_scan.py, catalog_visibility.py и beta_config.py.

## Скриншоты

Папка preview содержит 6 JPG: каталог, увеличенная карточка предмета, инвентарь, инструменты, English и компактное окно. Полные виды — 1536×864, компактный — 1320×760, карточка — 820×1164.

На снимках включён отдельный режим DEMO: 76 примерных записей, 38 мастер-кварцев, 22 занятых слота синтетического сохранения. В обычном запуске примеры не загружаются и не заменяют каталог пользователя. Тексты примеров не являются полной игровой базой.

## Практические границы проверки

Windows EXE и загрузка реального изменённого сохранения в игре здесь не проверялись. Готового EXE в архиве нет; для сборки предусмотрен Build_Qt_Preview_EXE.bat. Приложенные Linux-библиотеки PySide6 использовались для запуска и съёмки и не включаются в Windows-пакет.

Старый Tk-интерфейс в app.py не изменялся и не входит в эти 52 проверки; его графические тесты требуют отдельного дисплея. Нынешние скрипты запуска открывают Qt-версию.

Повторить актуальные проверки на Windows можно файлом Проверить_Qt_GUI_БЕТА.bat после первого запуска Qt-версии.
