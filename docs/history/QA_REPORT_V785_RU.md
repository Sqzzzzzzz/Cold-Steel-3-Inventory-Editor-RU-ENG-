# QA report — v7.8.5 Qt HUD BETA

## Проверено
- PySide6 GUI запускается в offscreen-режиме.
- Новый фон `assets/academy_hud_background.jpg` присутствует в сборке и используется Qt-оболочкой.
- Полный автоматический прогон тестов выполняется без изменения ядра формата сохранений.
- Проверены скриншоты окна 1650×920 и 1320×760.

## Изменения версии
- Заменён размытый фон интерфейса на новый оригинальный фон в более подходящей стилистике Cold Steel III: академия/город, холодно-синяя гамма, мягкое освещение.
- Читаемость текста и стеклянных HUD-панелей сохранена.

## Ограничения
- Windows EXE в этой среде не собирался и не запускался.
- Проверка загрузки отредактированного сохранения самой игрой по-прежнему требуется на Windows.
