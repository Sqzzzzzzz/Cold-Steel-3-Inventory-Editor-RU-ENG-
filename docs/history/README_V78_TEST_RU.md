# CS3 Inventory Editor v7.8 — Qt HUD BETA

Это **тестовая версия**: опубликованный на GitHub релиз v7.0.1 не изменяется.

## Как запустить

1. Распакуйте ZIP в отдельную папку.
2. Для запуска Qt-интерфейса используйте `Запустить_Qt_HUD_БЕТА.bat` либо `Run_Qt_Preview.bat`. Нужен установленный Python 3.10+ и возможность установить зависимости из `requirements-qt.txt`.
3. Для сборки автономного Windows EXE запустите `Build_Qt_Preview_EXE.bat`. Готовый файл: `dist\CS3_Inventory_Editor_v7_8_Qt_BETA.exe`.
4. Перед изменениями сделайте копию исходного сохранения. Сначала используйте «Сохранить копию…» и проверьте её загрузку в игре.

## Изменения относительно v7.7

- Настоящий запуск PySide6 проверен в Linux, скриншоты получены из работающего Qt-приложения.
- Стеклянные панели рисуют согласованный фрагмент академического фона (кэширование по размеру экрана).
- Увеличены строки, значки, элементы управления и читаемость карточки.
- Собственный набор векторных значков навигации, поиска и сохранения не зависит от системных шрифтов.
- При отсутствии оригинального игрового PNG Qt использует резервное изображение категории, а не пустое место.
- Адаптивная ширина дерева категорий, боковых панелей и столбцов на окнах 1320–1650 px.
- Убраны переносы внутри строк таблицы, добавлены подсказки с полным текстом ячеек.
- Значок избранного обновляется немедленно после клика.
- Остался только игровой стиль, русская и английская локализации.

## Примечания

- Скриншоты в `preview/` сделаны с тестовым сохранением и с пользовательскими PNG только в тестовой среде. Оригинальные игровые PNG и тексты в исходный проект **не встроены**.
- Для сканирования названий и описаний требуется установленная игра или локально импортированный пользовательский каталог.
- Визуальные эффекты близки к концепту, но **не являются его пиксельной копией**; системные рамки Windows и настройки масштабирования могут влиять на итоговый вид.
- EXE для Windows здесь не создавался и не запускался: предоставляется Windows-скрипт для его сборки на компьютере пользователя.
- Настройки беты отделены от стабильной версии: `%APPDATA%\CS3InventoryEditor_BETA`.

## Проверка

73 автоматических теста успешно пройдены в Linux с PySide6 6.12.0 и виртуальным дисплеем для старых Tk GUI-тестов. Включая пять новых тестов v7.8. Windows-сборка потребует отдельного теста на машине пользователя.
