# Проверка пропавших иконок v7.9.7

## Найдено

В снимках v7.9.6 отсутствовали шесть значков: оружие 100–102 и блюда 800–802. Демонстрационные записи использовали условные ID, которые в настоящей игре относятся к другим предметам или отсутствуют. Строгий подбор оригинального изображения правильно отказывался угадывать картинку. Все 115 исходных PNG целы.

Дополнительно воспроизведён случай обычного запуска: старый русский каталог содержал название и описание, но не категорию. Импорт EN сохранял правильную категорию только в английском наборе, а показ предмета продолжал использовать неполную русскую запись.

## Исправлено

- Все 76 демонстрационных ID, названия RU/EN и категории согласованы с переданными игровыми таблицами. Количества и сохранение демонстрации остаются синтетическими.
- Недостающие поля kind/category/type_code/character/element/rarity дополняются из английской записи того же ID. Русские тексты, исходные файлы кэша, явные значения и пользовательские правки не перезаписываются. Проверен перезапуск.
- Проверена очистка пустой Qt-иконки после импорта: изображение возвращается в таблицу и карточку, а введённое количество сохраняется.
- Самопроверка собранного EXE проверяет все 76 изображений демонстрации, включая декодирование Qt и подтверждённое происхождение. Ранее проверялся только мастер-кварц 3207.

Новые картинки не рисовались. Правила отказа для неизвестных, неподтверждённых и резервных ID сохранены.

## Проверки

В обеих базовых таблицах: по 1233 записи, 1181 видимая; в объединённом английском каталоге: 1240 записей, 1188 видимых. У видимых записей нет пропущенных иконок. Это проверка выбора оригинального PNG и его целостности, а не индивидуальная визуальная сверка каждого ID в игре.

Добавлены шесть регрессионных тестов: все демонстрационные изображения RU/EN без сети; согласованность синтетического сохранения; импорт и перезапуск старого кэша; сохранение явных метаданных/overrides; отказ для неизвестных ID; настоящий диалог импорта с ранее закэшированной пустой иконкой. Локальные регрессии и исходная самопроверка пройдены. Независимое ревью приняло исправления без замечаний.

Полная тестовая матрица Python 3.10/3.12/3.13, Windows EXE и его встроенная самопроверка выполняются GitHub Actions. Итог удалённой сборки смотрите для соответствующего коммита. Состав production-зависимостей не изменён; PySide6 остаётся ниже 6.12.

Сводка проверки данных: docs/qa/v797/icon-audit.json. Игровые таблицы и пользовательские каталоги в репозиторий не добавлены. Пользовательские сохранения не изменялись.
