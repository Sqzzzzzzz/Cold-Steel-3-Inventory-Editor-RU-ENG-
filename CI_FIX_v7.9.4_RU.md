# Исправление GitHub Actions для CS3 Inventory Editor v7.9.4

По журналам GitHub Actions от 28.10.2026:

- Linux CI: отсутствует системная библиотека `libEGL.so.1` для импорта PySide6. В `tests.yml` добавлена установка `libegl1` и двух распространённых зависимостей Qt.
- Windows CI: запуск всех Tkinter GUI-тестов перед сборкой PySide6 EXE был нестабилен из-за среды Tcl/Tk и геометрии окна. В Windows workflow исключены три набора устаревших Tk GUI-тестов, при этом полный набор остаётся в Linux CI. Qt GUI, сохранения и основные регрессионные тесты в Windows остаются активными.
- Windows: проверка путей теперь сравнивает идентичность файлов (`samefile`), а не строковое написание `RUNNER~1` и `runneradmin`.
- Проверка иконок больше не требует отсутствующего в публичном исходном архиве `QA_NATIVE_ICONS_V793.json`; контроль SHA256 каждого PNG сохранён.
- Пакетирование Windows EXE включает `icons/original`, но не старый каталог `icons/by_category`.

**Важно:** если `icons/by_category` осталась в GitHub после обновления, удалите устаревшую папку через GitHub Desktop. Перед публикацией релиза дождитесь зелёных проверок и проверьте скачанный Windows EXE.
