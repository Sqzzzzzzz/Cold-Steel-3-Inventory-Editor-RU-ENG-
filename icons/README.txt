Original Cold Steel III item artwork

The original/ folder contains 115 authentic game images distributed as public Kiseki Wiki image files. These PNGs are not generated or redrawn. Large source images were only resized to a maximum of 256 pixels and encoded as PNG.

sources.json records each exact source page, CDN URL, source and output SHA-256, and image dimensions. The artwork belongs to its respective rights holders; the editor code license does not relicense game artwork.

Exact item artwork takes precedence over family artwork. Per-item user overrides can be placed in by_id/<ID>.png. An unavailable original remains unavailable; the Qt interface never substitutes a generated item image.
