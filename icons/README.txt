ПРЕДВАРИТЕЛЬНЫЙ МАКЕТ: изображения в by_category являются специально созданными условными пиктограммами, а НЕ иконками из Cold Steel III.
Чтобы заменить их на настоящие игровые иконки, разместите PNG с именем ID.png в папке icons/by_id; программа предпочтет конкретные значки перед категориями.
Изображения оригинальных значков должны быть получены из законно установленной игры/доступных источников.
