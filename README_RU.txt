CS3 Inventory Editor v7.9.6

Готовая версия: распакуйте Windows ZIP и запустите CS3_Inventory_Editor.exe.
Исходники: запустите «Запустить.bat» либо установите requirements.txt и
выполните python qt_window.py. Новый интерфейс работает на PySide6.
Старый интерфейс app.py сохранён для совместимости.

При первом запуске укажите папку игры и сохранение saveXXX.dat.
Названия и описания читаются из вашей игры; таблицы и сохранения в публичный
архив не включены. Встроенные оригинальные PNG перечислены в манифесте.
Сначала сохраняйте отдельную копию и проверяйте её в игре.
Подробнее: README.md и README_EN.md.
