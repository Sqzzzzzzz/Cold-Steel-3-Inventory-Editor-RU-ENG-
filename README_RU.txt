CS3 Inventory Editor v7.0 — GitHub Source Edition

Публичная версия содержит только код и условные иконки. Исходные игровые
названия, описания, таблицы .tbl и оригинальные изображения НЕ включены.
После запуска «Запустить.bat» программа найдёт установленную игру, либо
попросит указать её папку. Каталог появится после сканирования.
Для русского текста предметов необходима таблица из русифицированной игры;
английский текст будет считан из исходных английских таблиц на ПК игрока.
Подробнее: README_EN.md и README_GITHUB.md.


ВЕРСИЯ 7.0 — ФИНАЛЬНЫЙ АУДИТ
- Внесены транзакционные массовые изменения: одна проверка инвентаря
  вместо повторной проверки после каждого из выбранных предметов.
- При любой ошибке пакетной операции данные остаются неизменными.
- Исправлены строка версии и английский текст ошибки диапазона количества.
- Добавлен автономный audit_assets.py для контроля наличия игровых иконок.
- Программа не включает оригинальные игровые PNG в публичные исходники.
- Загрузка всех возможных изменённых сохранений непосредственно игрой
  по-прежнему требует практической проверки.
