# Contributing

Issue reports are welcome. Include the editor version, game edition, Python version and reproducible steps. **Do not upload a save containing private information, copyrighted original game tables or original game image files to a public issue.** Use a small synthetic test case where possible.

Code contributions: avoid bundling proprietary game data; use stable item IDs instead of matching translated names; provide unit/regression tests; retain safe backups and atomic save operations. UI labels added to `app.py` must have English equivalents in `i18n.py`.

The repository is community-maintained and unofficial.
