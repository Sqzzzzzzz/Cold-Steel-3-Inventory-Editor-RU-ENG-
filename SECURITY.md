# Security and data safety

This offline editor handles local game saves. **Back up original saves and close the game before overwriting.** Only files matching the measured NISA Windows save structure are accepted. If your edition uses a different format, do not force the editor to write it.

Official icon images may be downloaded from the community wiki; importing icons, catalogs or saves from untrusted sources is at your own risk. Do not run third-party EXEs claiming to be this editor without checking the source or release authenticity.

To report a security problem, create a private GitHub security advisory once a repository has been created (Repository → Security → Advisories). Do not post exploits or personal save contents publicly.
